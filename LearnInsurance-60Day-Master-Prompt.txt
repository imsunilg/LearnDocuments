SECTION 2 - TECHNOLOGY STACK
==============================================================================

Frontend
- Latest stable ReactJS at the time of implementation (verify first)
- React + TypeScript + Vite, functional components, Hooks
- React Router, Context API where appropriate
- Redux Toolkit ONLY if it becomes genuinely useful
- TanStack Query where appropriate
- Axios (or modern HTTP client)
- React Hook Form + Zod
- Modern CSS approach, responsive UI
- Reusable: DataTable, SearchBox, FilterPanel, FormField, Select, DatePicker,
  Modal, ConfirmationDialog, Toast, Loader, EmptyState, ErrorState, Pagination
- Loading, error and empty states everywhere

Backend
- ASP.NET Core 9 Web API, C#
- Clean Architecture principles
- REST APIs, DTOs, FluentValidation, Dependency Injection
- Entity Framework Core only where appropriate
- Repository/Service pattern only where justified
- Global exception handling, logging, Swagger/OpenAPI
- JWT authentication, role-based authorization

Database
- PostgreSQL, database name: LearnInsuranceDB
- Primary keys, foreign keys, unique constraints, check constraints, indexes
- Audit fields on every table: Id, CreatedDate, CreatedBy, ModifiedDate,
  ModifiedBy, IsActive
- Choose UUID or BIGINT for keys and DOCUMENT THE DECISION (Day 07)
- Prefer PostgreSQL functions (returning JSON for complex/read operations)
- No large inline SQL inside application code
